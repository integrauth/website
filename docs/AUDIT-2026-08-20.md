### Agent D — Worker/server (DONE, 3 fixables, no security drift)

**FIX-2 (med)** `worker.ts:77`: `void maybeSweepExpiredExamIpHashes(env.DB, p => ctx.waitUntil(p))` —
the sweep's CLAIM (claimSweepWindow D1 write) races the response un-protected; on D1-free fast
routes (/auth/start) it can be torn down, silently skipping that hour's scrub (self-healing but
breaks the documented retention bound). Fix:
`ctx.waitUntil(maybeSweepExpiredExamIpHashes(env.DB, p => ctx.waitUntil(p)).catch(() => undefined))`.

rejection, contrary to its own comment.
