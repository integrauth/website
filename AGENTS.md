# Agent Instructions

This repository's instructions for AI coding agents live in **[CLAUDE.md](./CLAUDE.md)**,
in the repository root. Read it before making any changes — it covers architecture,
conventions, invariants, gotchas and workflow rules, and applies to every AI tool or
model working in this repo, not just Claude.

`AGENTS.md` exists as a pointer, not a fork: keep a single source of truth in
`CLAUDE.md` rather than maintaining two copies of the same guidance. If you update
project instructions, update `CLAUDE.md`; this file should rarely need to change.
